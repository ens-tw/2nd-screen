SDA / SCL are being repurposed

GP2 and GP3 must be configured for UART0. Keep the STEMMA QT port and other devices on those I²C lines disconnected while using this pin plan.

03

Mode switch and spare pins

First test: CMD / command mode

Leave the MOD pin unconnected and set the module’s slide switch to CMD. Start the UART test at 9600 baud, 8 data bits, no parity, 1 stop bit, with RTS/CTS enabled.

Send AT followed by CRLF (\r\n); a responding module returns OK. Use ATI to read its firmware information. This requires UART test firmware or a suitable serial bridge; live_mirror.py currently reads USB capture data.

Then: UART / data mode

After the command test, set the slide switch to UART / DATA for the transparent BLE UART service. A host BLE client must connect and enable notifications.

Keep DFU and other unused pins unconnected. No connection to the Feather RST pin is required. The bridge should use hardware flow control in both modes.

The Bluefruit firmware supports higher UART baud settings, but Adafruit notes reliability limitations on the nRF51. Measure end-to-end throughput before using the full screen stream; a fast UART setting does not establish BLE throughput.

04

Connect, power, verify

  1. STEP 1

    Connect with power off

    If the SPI probe is attached, turn off the display evaluation board first. Then unplug Feather USB and any battery or separate Bluefruit supply. Add the six wires by label.

  2. STEP 2

    Use the Feather supply

    Power the Feather by USB before turning the display evaluation board back on. The 3V → VIN wire powers Bluefruit. The module accepts 3.3 V at VIN; all UART and flow-control signals in this guide use 3.3 V.

  3. STEP 3

    Run a UART test first

    Verify AT → OK in CMD mode, then test BLE data transfer. The current project firmware needs a UART/BLE bridge addition before these wires carry the screen stream.

3–5 V refers to Bluefruit’s input compatibility

The Feather RP2040’s GPIOs use 3.3 V logic. Use the 3.3 V connections shown here; do not apply 5 V to a Feather GPIO.
